# 🚀 Featured Project

## 🔄 End-to-End CI/CD Pipeline

**Status: ✅ Completed**

My first end-to-end DevOps portfolio project connecting source control, CI/CD, containers, and cloud deployment.

### Architecture

```text
Developer
    │
    ▼
GitHub
    │
    │ Webhook
    ▼
Jenkins
    │
    ├── Build
    ├── Test
    ├── Docker Build
    └── Docker Push
            │
            ▼
       Docker Hub
            │
            ▼
        AWS EC2
            │
            ▼
      Docker Container
            │
            ▼
       Web Application
```

### Technologies

`GitHub` · `Jenkins` · `Docker` · `Docker Hub` · `AWS EC2` · `Linux` · `SSH` · `Webhook`

### What I implemented

* Created a Flask web application with `/` and `/health` endpoints
* Created a Dockerfile and containerized the application
* Built and tested the application locally
* Configured Jenkins for CI/CD automation
* Connected GitHub to Jenkins using a webhook
* Built Docker images through Jenkins
* Pushed Docker images to Docker Hub
* Deployed the containerized application to AWS EC2
* Used SSH-based deployment
* Troubleshot Docker authentication, ports, deployment configuration and webhook connectivity

### Repository

🔗 **[View CI/CD Project](https://github.com/akhilapm55/devops-cicd-pipeline)**

### Key lesson

> A CI/CD pipeline isn't just about connecting tools. The real work is understanding what happens when one connection, credential, port, service, or deployment step fails.
